# Award logos

Official logos for the awards listed on the site. Each file shows next to its line as soon as it is
here, at the next build. Light (white or pale) versions read best on the dark site. SVG is best, PNG or WebP also work.

| File name | Line |
| --- | --- |
| `rts.svg` | RTS Craft & Design Awards 2024, winner (the RTS sends winners an official winner logo) |
| `music-and-sound.svg` | Music+Sound Awards 2024, nominee (finalists get an official badge) |
| `bafta.svg` | Composer of the BAFTA-winning series *We Are Lady Parts* |

Use the files the award bodies supply, as they are. BAFTA approves every use of its logo and mask
(permission form at bafta.org/press/logos), and its winner and nominee logos are only for the named
winners and nominees, so leave `bafta` out unless BAFTA has said yes.
